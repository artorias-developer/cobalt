# Barotrauma

This tutorial explains how to set up a Barotrauma server in the Cobalt dashboard.

## Changing configs

1. Open the servers page.

2. Find the server you want to change settings in the table and click the first button in the actions column.

3. Click the stop button in the control block.

4. Open the files tab at the top.

   ---

   ### `serversettings.xml`

   1. Open the `serversettings.xml` file in the file editor.

   2. Update the settings.

   1. Open the `Data/clientpermissions.xml` file in the file editor.

   This table refers to version `23799137`. Some settings may not be available in earlier versions.
   
   | Key           | Type   | Default   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

   | `accountid`   | string | _(blank)_ | A player's Steam ID in the format `STEAM64_<steam_id>`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
   | `permissions` | string | _(blank)_ | List of permissions.<br>`ManageRound` - Allows players to start and end rounds.<br>`Kick` - Allows players to kick other players.<br>`Ban` - Allows players to ban other players.<br>`Unban` - Allows players to unban other players.<br>`SelectSub` - Allows players to select the sub when the selection mode is on "Manual".<br>`SelectMode` - Allows players to select the gamemode.<br>`ManageCampaign` - Same as giving ManageMoney, SellInventoryItems, SellSubItems, ManageMap, and ManageHires permissions.<br>`ConsoleCommands` - Allows players to use Console Commands. ## Adding mods

1. Open the servers page.

2. Find the server you want to add mods in the table and click the first button in the actions column.

3. Click the stop button in the control block.

4. Upload mods using one of the following methods:

::::details File manager
1. Open the files tab at the top.

2. Open the `LocalMods` folder in the file manager.

3. Click the upload button in the bottom left corner.

4. Select the mods files from your device.

5. Open the `config_player.xml` file in the file manager.

6. Add the mod paths to the list inside the `<contentpackages>` block:

```xml
<contentpackages>
  <!--Vanilla-->
  <corepackage
    path="Content/ContentPackages/Vanilla.xml" />
  <regularpackages> <!-- [!code ++] -->
    <package <!-- [!code ++] -->
      path="LocalMods/3756243869/filelist.xml" /> <!-- [!code ++] -->
    <package <!-- [!code ++] -->
      path="LocalMods/3756485107/filelist.xml" /> <!-- [!code ++] -->
  </regularpackages> <!-- [!code ++] -->
</contentpackages>
```

7. Click the save button in the bottom right corner.
